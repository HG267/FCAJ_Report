Event 1

This event included multiple tracks and information. However, I will only present some of the keynotes that stimulated my interest!!!

Summary Report: “AWS Cloud and AI Day”

Event Objectives

  • Explore how AWS equips builders with tools and resources to push the boundaries of what’s achievable
  • Find out how AWS’s newest innovations can help build, scale, and transform business
  • Discover how AWS uses agentic systems to empower developers, modernize workloads, and secure organizations worldwide

Speakers

  • Eric Yeo - Country General Manager Malaysia, Vietnam, Indochina, AWS
  • Dr. Werner Vogels - CTO, Amazon.com
  • Nguyen Hoang Diep - Soluton Architect, AWS Vietnam
  • Doan Thien Long - Software Engineering Manager, TCBS Vietnam
  • Trung Nguyen - Technical Account Manager, AWS Vietnam
  • Tan Huynh - Technical Account Manager, AWS Vietnam
  • And other Speakers

Key Highlights

AWS Spirit & Driver to Innovations.

  • History of solving the unsolvable problems: The spirit of continuing innovations and shoutout to builders who worked hard behind the scene.

  • Real world expectations: to use key-value database -> The introduction of well-known Amazon DynamoDB Database -> All the innovations come from the ideas of satisfying customers (Nitro Hardware, Virtualization, AZs, Local Zones, Lambda, etc).

AI-Driven Development Lifecycle (AI-DLC)

AI Agent used in normal day -> Only a few problems occur -> Fixed easily.

AI Agent used in complex project (ERP, Finance, etc) -> Problems occurs: functional complexity, context loss -> Quality drops.

Methodologies applied to fit AI in SCDL:

  • Inception Phase: Requirement Analysis, Planning -> User Stories with Acceptance Criteria, NFR definitions, Risk descriptions and Bolts (Sprinst but shorter).
  • Construction phase: Domain Design, Logical Design, Code Generation & Testing
  • Operations phase: Deployment, Automatic Observability -> Developers validate numbers, approve - AI executes scaling policy.

AI-Native Delivery at TCBS

SDLC at TCBS must balance between Delivery Pace and Quality of Released Product by ensuring:

  • CLear Context for Agent: Gathering input -> clear Spec Context (through requirements, planning, etc) -> Accelerating Delivery Pace.
  • Specifying Task Boundary for AI: How to Implement a task, Where to Test the result, What specs should be applied to Control the quality -> Maintain Quality of the Product.

AWS Security Agent from Design to Deployment

AI can make softwares vulnerable from the inside or outside of a business -> the need of Security Agent.

Security Agent is an autonomous frontier AI agent that proactively secures applications across the entire software development lifecycle. Including 4 presented features:

  • Design Review: Provide design documents (diagrams, architectures etc) -> Evaluate design documents -> Produce findings -> Security vulnerability (feedbacks increase agent knowledge base).
  • Threat Model: Extract information and create threat models
  • Code Review: Provide source codes -> Agent evaluate and find threat inside logic -> Validate findings in a sandbox environment -> Recommend changes.
  • Penetration Testing: Authentication with endpoints -> Orchestratiing sub-Agents to test the system simultaneously-> Managed Execution with a sub-agent to validate test playbooks -> LLM strategic agent revalidate all steps, connect the threats, mimic attack scenario and provides preventing suggestions -> CLean up all test results, findings, sandbox and provide final suggestions.

Key Takeaways

Builder Mindset

  • Be Curious: Always learning and ask myself questions about the problem
  • Be Confident: There is always a solution to the problem, this has been showed in AWS History of Development.
  • Be Hunger for Innovation: Extraordinary things can be made with enough determination.

Apply AI in SDLC (AI-DLC)

  • Human Role change:
    • Coders -> Trade-offs Decision Maker
    • Planners -> Plan Validator
    • Testers -> Output Assessment
  • AI in SDLC can boost the development process in quality and pace (Ceremonies).
  • Minimize lifecycle: Reduce the steps taken for 1 sprint -> 3 steps for a bolt.

Accelerating Delivery Pace and Maintaining Product Quality

  • Input matters: Analyzing Requirements, Plannings before fetch to AI, rework on input if neccessary
  • Apply Agent Loop: Human factor always involves in Review, Test, CI process before Agent can take action
  • Task Ownership model:
    • PM: Describe goals, business logics, priority
    • Engineer: focus on build, verification

Apply AWS Security Agent in SDLC

  • Software can be vulnerable from inside: Developers may make mistakes from logics to the way they use AI -> cause severe security threats
  • Software can be vulnerable from outside: With AI, blackhat may construct attacking scripts in just minutes -> increase the attck rate.
  • AWS Security Agent in SDLC: Help secure the system from planning phase to release phase -> AWS Security Agent can be involved in every step of developments -> reduce threats and vulnerablity.

Applying to Work

  • Apply AWS Security Agent to current projects: Ensuring security accross phases in SDLC
  • Feed AI with proper information: Define requirements, scope, planning before feeding the context to AI so that these agents can work properly and provide results as expected.

Event Experience

Attending the “AWS Cloud and AI Day” workshop was extremely valuable, giving me the knowledge of AI in SDLC that I have never been experienced before. With presented mindsets, stories and the ways to use AI in mordern days, I believe these factors can help boost my FCAJ project and provide the most satisfactory results.

Learning from highly skilled speakers

  • Experts from AWS and major tech organizations shared best practices in modern application design using AI and tools.
  • Through real-world case studies, I gained a deeper understanding of applying AI and Spec-Driven Approach to large projects.

Lessons learned

  • Applying AI in SDLC helps boost Delivery pace and maintaining Quality of a Product.
  • As AI become more approachable, more and more threats can be observed from inside and outside of a system.
  • With AWS Security Agent, engineering can ensure system security through every phase of SDLC with the help of Agents.
